This page exercises Mnp.Api only (porting-request lifecycle + number-ownership lookup); donor validation and carrier/customer notifications happen behind the scenes via Mnp.MockExternalApis and are visible as outbox rows above, not called directly from here. For the full picture run all three processes locally: Mnp.MockExternalApis, Mnp.Worker, and Mnp.Api (see README.md). Known, documented gaps carried into this demo: no scheduled SLA/timer sweep (nothing moves a request on its own just because time passed — use the action buttons), and a blocked fraud-velocity attempt (4th submission for the same MSISDN within 7 days) surfaces only as a generic error, not a friendly message.
